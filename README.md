# LoRa P2P Communication: STM32 and ESP32

STM32F302 implementation of LoRa Point-to-Point (P2P) communication with an ESP32, using a Ra-01 (SX1278) module over SPI. Built for a special course at DTU.

This repository contains the STM32 side of the project. It receives LoRa packets sent from an ESP32 running the [nopnop2002/esp-idf-sx127x](https://github.com/nopnop2002/esp-idf-sx127x) example.

## What's in this repo

- **`LoRa_P2P_Communication_with_STM32_and_ESP32.pdf`** — the full step-by-step how-to guide, covering ESP-IDF setup, ESP32 wiring/code, STM32CubeIDE/CubeMX setup, STM32 wiring/code, LoRa parameters, and P2P test results
- **`Core/Src/main.c`** — the STM32 application code: initializes the SX1278 LoRa driver and continuously listens for incoming packets
- **`Core/Src/SX1278.c`, `Core/Inc/SX1278.h`** — the LoRa driver logic (from wdomski/SX1278, see Credits)
- **`Core/Src/SX1278_hw.c`, `Core/Inc/SX1278_hw.h`** — the hardware abstraction layer connecting the driver to STM32 HAL (SPI/GPIO calls)
- **`stm32-lora-ra01.ioc`** — the STM32CubeMX project file, containing the full pin and peripheral configuration (SPI3, GPIO). Open this in STM32CubeMX to view or modify the hardware configuration
- **`Drivers/`** — auto-generated STM32 HAL and CMSIS libraries (not written by us, generated by CubeMX)

## Where the LoRa Integration Was Added

If you're setting this up from a fresh CubeMX project rather than cloning this repo, here's exactly where the LoRa-specific code was added in `Core/Src/main.c` (inside CubeMX's `USER CODE` markers, so it survives regeneration):

- **`/* USER CODE BEGIN Includes */`** — added `#include "SX1278.h"` and `#include <stdio.h>`
- **`/* USER CODE BEGIN PV */`** — added the `SX1278_hw_t`, `SX1278_t`, `ret`, and `buffer` variables
- **`/* USER CODE BEGIN PFP */`** — added the `_write()` function to redirect `printf` over UART2
- **`/* USER CODE BEGIN 2 */`** — added the LoRa module pin assignment, `SX1278_init(...)`, and `SX1278_LoRaEntryRx(...)` calls
- **`/* USER CODE BEGIN WHILE */`** (inside the main loop) — added `SX1278_LoRaRxPacket(...)` and the packet read/print logic

Additionally, in **`Core/Src/SX1278_hw.c`** (copied from the wdomski/SX1278 driver), the original includes:
```c
#include "gpio.h"
#include "spi.h"
```
were replaced with:
```c
#include "main.h"
```
since this project uses CubeMX's simplified structure (all peripherals in `main.c`/`main.h` rather than separate files).

See the PDF guide for the full walkthrough with explanations.

## Full Guide

The complete step-by-step how-to guide, covering both the ESP32 and STM32 setup, wiring, and testing, is available here: [LoRa_P2P_Communication_with_STM32_and_ESP32.pdf](LoRa_P2P_Communication_with_STM32_and_ESP32.pdf)

## Hardware

- STM32F302R8 Nucleo-64
- Ra-01 (SX1278) LoRa module, 433 MHz
- ESP32 DevKit (for the transmitting side, see guide)

## Pin Configuration

| Ra-01 Pin | STM32 Pin | Function |
|-----------|-----------|----------|
| 3.3V | 3V3 | Power |
| GND | GND | Ground |
| NSS | PB0 | SPI Chip Select |
| SCK | PC10 | SPI Clock |
| MISO | PC11 | SPI Data Out |
| MOSI | PC12 | SPI Data In |
| RST | PB1 | Reset |
| DIO0 | PA5 | Interrupt (TX/RX done) |

## Building

Requires STM32CubeIDE. Open the project via **File → Open Projects from File System** and build normally.

**Note:** SPI3 must be configured with **Data Size: 8 Bits** in CubeMX (this project's `.ioc` already has this set correctly).

## Results

Achieved 0% packet loss over ~15-20m indoors through multiple concrete floors and walls, at SF7/125kHz/CR4-5. See the full guide for detailed test results and LoRa parameter explanations.
